# 🤖 MultiTool Telegram Bot

Многофункциональный Telegram-бот с системой управления пользователями и набором вспомогательных инструментов.

## Возможности

- **📧 Интеграция с API временной электронной почты**
- **🎨 Автоматическое заполнение шаблонов изображений**
- **🔐Админ-панель** - выдача и отзыв доступа, статистика пользователей
- **👥Система доступа** - функции бота доступны только пользователям, добавленным админом

## 🛠️Стек

Python, Aiogram 3, SQLite, Pillow

## 📦Установка и запуск

1. Клонировать репозиторий
```bash
git clone https://github.com/qribix/arbitrage-helper-bot.git   
cd arbitrage-helper-bot
```

2. Установить зависимости:
```bash
pip install -r requirements.txt
```
3. Открыть config.py и вставить свои данные:
   >- BOT_TOKEN — токен бота из @BotFather
   >- ADMIN_ID — твой Telegram ID
   >- CONTACT — ссылка для кнопки связи

4. Запустить:
```bash
start.bat
```
